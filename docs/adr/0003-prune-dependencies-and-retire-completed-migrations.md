# Prune unused dependencies and retire completed migration scripts

The root `package.json` had accumulated dependencies with zero remaining references in source or config (`@ngrx/component-store`, `@ngrx/operators`, `@ngrx/router-store`, `rxfire`, `jasmine-marbles`, `ts-node`, `jest-util`) — we removed all seven. `@angular-architects/ddd` and `@ngrx/schematics` are equally unused today but were kept deliberately as scaffolding reserved for future use; don't "fix" that in a later cleanup pass without checking here first. `@ngneat/until-destroy` (9 call sites, replaceable with `DestroyRef`/`takeUntil`) and `lodash-es` (3 call sites, replaceable with native code) are used but replaceable — deferred as follow-up work rather than refactored in the same pass as the mechanical deletions above.

Separately, `functions/scripts/lib/flatten-exercise-translations.ts` and `migrate-instructions.ts` were the one-time migrations that executed ADR-0002's data flattening (already run against dev and prod). `survey-exercise-shapes.ts` was a read-only pre-deploy check written to de-risk that same ADR-0002 rollout (per its own docstring) — also done, once the deploy it was verifying had shipped. `parse-exercise.ts` never ran at all — its `request` runtime dependency was added to devDependencies as a type-only stub (`@types/request`) back in the original 2023 commit but the actual `request` package was never installed. All four were deleted rather than kept as living reference code; git history (`git log -- <path>`) is the intended way to recover them if a future migration needs the pattern. Deleting them also dropped `jsdom`, `@types/jsdom`, and `@types/request` from `functions/scripts/package.json`, and let `shared-package` there be bumped from the stale `5.2.0` pin to `5.6.0`, matching root and `functions/` — the bump is what surfaced that `survey-exercise-shapes.ts` referenced `COLLECTIONS.TRANSLATIONS`, a constant 5.6.0 no longer exports, confirming it was safe to retire alongside the other two.

## Consequences

- If multilanguage-era data-migration or verification logic is needed again, look it up via `git log -- functions/scripts/lib/flatten-exercise-translations.ts`, `migrate-instructions.ts`, or `survey-exercise-shapes.ts` rather than expecting a live file in the tree.
- `functions/scripts` no longer has any script that scrapes exercise data from a URL (`parse-exercise.ts` is gone); it was non-functional since inception, so nothing working was lost.
- `functions/scripts`'s remaining `shared-package` consumers (`update-user-role.ts`, `update-exercise-ownership.ts`) now run against the same `shared-package` version as the rest of the repo.
